前言

本文档主要介绍MadCap Flare软件的基本操作，旨在帮助资料部同事输出网管产品的联机帮助、操作指南。

文档概览

文档目的

本指南主要介绍MadCap Flare软件的基本概念、相关操作、常见问题，方便不熟悉该软件的同事迅速了解软件的常用操作，提高系统产品相关的工作效率。

目标读者

本指南的主要读者是英文技术写作、翻译、审校人员。

适用范围

本指南主要适用于网管产品的联机帮助、操作指南、产品概述等产品资料。

基本概念

MadCap Flare 是一款专为技术写作开发的同源写作软件，旨在将文档切分为单个模块，以维护单个模块的方式维护整个文档，最大限度地重复使用内容，并输出到多个渠道。

在翻译组的系统产品维护工作中，主要涉及该软件的以下几个概念。

Topic

Topic相当于文档中的小节，包含了针对某个对象、话题的信息。

{width="6.845833333333333in" height="3.7381944444444444in"}

Target

Target是最终输出的文件，由多个Topic组成。

{width="6.845833333333333in" height="3.7381944444444444in"}

TOC

TOC（Table of Content）是Target的目录文件。

{width="6.845833333333333in" height="3.7381944444444444in"}

Snippet

Snippet包含了一个Flare项目在不同渠道能多次利用的内容，可包括文字、图片、表格等。

{width="6.845833333333333in" height="3.7381944444444444in"}

Text Editor

Text Editor显示该页面的具体内容，如文字、图片、表格。

{width="6.845833333333333in" height="3.7381944444444444in"}

XML Editor

XML Editor显示该页面内容的代码信息。

{width="6.845833333333333in" height="3.7381944444444444in"}

工作流程

  • 更新文档（多数）

a. 打开 Flare 文件。

  i.  在 SVN 找到上个版本的 Flare 压缩文件包，拖拽保存到本地。

{width="6.845833333333333in" height="4.6in"}

+-----------------------------------------------------------------------+ | {width="0.6305555555555555in" | | height="0.24583333333333332in"} | +=======================================================================+ | > 一些 Flare 文件较大，保存到本地耗时较久，属于正常情况。 | +-----------------------------------------------------------------------+

ii. 解压文件包。

解压后，文件夹一般包含
"Analyzer"，"Content"，"Filesync"，"Output"，"Project"文件夹及
.FLPRJ 文件。

{width="6.8381944444444445in" height="3.745833333333333in"}

iii. 双击打开 .FLPRJ 文件。

iv. （可选）如果打开文件后，系统弹出"New Updates Available"对话框，单击"Cancel"。

b. 对照中文的修改记录，完成英文 Flare 文件的更新。

c. 发布文件。

d. []{#交付文件 .anchor}交付文件。打开"Flare 本地文件夹 > Output > 工号文件夹 > 交付文件所在文件夹"。

  • 如果交付操作指南、产品概述，将 .pdf 文件发给需求人即可。

{width="6.8381944444444445in" height="3.7694444444444444in"}

  • 如果交付联机帮助，先将整个联机帮助文件夹压缩打包，再发给需求人。

{width="6.8381944444444445in" height="3.754166666666667in"}

  • 制作全新文档

直接用中文 Flare 文件修改，省去调整格式的时间。

a. 将中文 Flare 文件拖拽保存到本地。

a. 打开中文Flare 文件，另存为英文 Flare 文件。

b. 修改内容后交付（步骤和要求同更新文档，参考 交付文件）。

添加新的Topic

使用场景

若此次修订中需要增加新的小节，则需要添加Topic。

以给"BasicOperations"一章添加名为"Learn Flare"的topic为例。

步骤

  1. 单击"Project Organizer > TOCs"。

  2. 双击文件名，打开文件目录。

{width="5.761805555555555in" height="3.1458333333333335in"}

  1. 右键单击一级标题，选择"Add New Topic..."。

  2. 单击"Folder"后面的{width="0.2847222222222222in" height="0.2152777777777778in"}。

  3. 在"Select Folder"对话框中，选择一级标题文件夹（"BasicOperations"），单击"OK"。

{width="3.7847222222222223in" height="2.8694444444444445in"}

  1. 在"File Name:"对话框输入topic的标题（"Learn Flare"）。

  2. 单击"Add"。

系统自动打开并停留在"Learn Flare"页面。

打开跳转页面

使用场景

联机帮助中，每个章节的首页都有本章二级标题的跳转链接汇总。可点击跳转链接到某个页面，再做修改。比如，以下页面的蓝色字体均为跳转到其他页面的超链接。要打开"Introduction"页面，按住【Ctrl】键，同时单击"Introduction".

步骤

按住Ctrl键，单击页面标题（蓝色字体）

{width="5.645833333333333in" height="2.915277777777778in"}

添加超链接

使用场景

各个一级标题下，有一个topic用于跳转到二级标题的页面。

比如，在"Basic Operations"页面添加"Learn Flare"页面的跳转链接。

{width="5.761805555555555in" height="3.1458333333333335in"}

步骤

  1. 插入Learn Flare标题

  2. 复制粘贴

i. 复制已有topic的标题和简介，粘贴到适当位置。

ii. 将topic标题改为"Learn Flare"，修改简介。

iii. 右键单击"Learn Flare"，选择"Edit Hyperlink"。

  • 直接输入

i. 在适当位置输入"Learn Flare"与简介。

ii. 选中"Learn Flare"后，单击右键。

iii. 选择"Insert > Hyperlink"。

  1. 在"Insert Hyperlink"对话框中，选择"Learn Flare"。

  2. 单击"OK"。

{width="5.761805555555555in" height="4.815277777777778in"}

设置发布格式

使用场景

发布到联机帮助与操作指南的内容可能有出入。编辑Topic时，需要选择内容发布到哪种格式。

步骤
  1. 右键单击要修改的内容，选择"Conditions..."。

{width="5.207638888888889in" height="3.6618055555555555in"}

  1. 选择输出格式。

  2. 勾选"hlp"，内容输出到联机帮助。

  3. 勾选"opg"，内容输出到操作指南。

  4. 单击"OK"。

打开拼写检查

  1. 选择"Projects > Project Properties"。

  2. 点击"Language"。

  3. 选中"English (United States)"，点击"OK"。

  4. 选择"Tools"。

  5. 勾选"Spell check while typing\"。

  6. 重启项目，更改生效。

图片相关操作

添加图片到resources文件夹

使用场景

网管的联机帮助和操作指南基本每个步骤都要配图。插入的图片多为页面截图。

以用企业微信截图为例。

步骤

  1. 用企业微信截图。

  2. 右键单击截图，给图片命名，保存到非加密盘（一般为F盘）。

  3. 在沙盒中打开非加密盘。

  4. 将该图片复制粘贴到"resources"文件夹下对应的文件夹内。

发布文件

使用场景

文件修订完成后，按需求输出交付文件。

步骤

  1. 点击"Project Organizer"。

  2. 把发布文件设置为Primary Target。参考7.1 设置Primary Target。

  3. 把发布内容的TOC设置为Master TOC。参考7.3 设置Master TOC。

  4. 单击"Project > Publish Primary"。

  5. 在"MadCap Flare 2017"对话框中，选择"是"。

  6. （可选）双击发布状态栏的任一位置可打开文件。
